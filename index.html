📥 Import from PCGS Set Registry (CSV)
Import your PCGS "My Inventory" CSV export. NGC cert numbers found in comments are detected automatically, Sold/For Sale status is preserved, and each coin gets a new MX-# number. You'll see a preview before anything is saved. Photos are not in the CSV — add them per coin afterward.
ℹ️ About
MX Registry — after uploading an update to GitHub Pages, confirm this version number changed to verify the new build loaded (force-close and reopen the app if it didn't).
🛠 Maintenance
Scans for coins sharing the same MX inventory number. The oldest coin keeps its number; later ones (e.g. from an import) are assigned fresh MX numbers continuing after the highest in use.
💾 Backup & Restore
Exports all coins (with photos) into one .json backup file you can save anywhere or move between devices. On iPhone, backups save to the Files app (Downloads); to restore, tap Restore Backup and pick the backup file from Files. Older .mxreg backups restore fine too.
